# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or an exposed webhook URL. Use GitHub's private vulnerability reporting for this repository. Include reproduction steps and impact, but replace every workflow URL, token, tenant identifier, and personal detail with a clearly marked placeholder.

If a real workflow URL was exposed, regenerate it in Power Automate immediately. Removing it from a report or commit history is not sufficient because copies may already exist.
